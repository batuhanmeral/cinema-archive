# Sinema Arşivi

A bilingual (Turkish/English) digital archive of cult films, built as a static website: [sinemaarsivi.com](https://sinemaarsivi.com).

Film membership comes from published lists (Wikipedia's "List of cult films" and film-movement sources); film data comes from TMDB and Wikidata.

This product uses the TMDB API but is not endorsed or certified by TMDB.

## Features

- Film pages with credits, trailer, tags and similar films; movement and collection pages; a weekly rotating home page.
- An archive of every film, filtered by genre, theme, country, decade and language, sorted by year, title or popularity; the filters live in the URL, so any view can be shared.
- A site search in the navbar (press "/") that finds films by Turkish, English or original title and by director, plus movements and collections.
- A "Random film" button that opens a film page at random.
